# MARK STREBEN — THE PRIVATE EDITION · Version 2

Preserves the original homepage aesthetic and adds four separate pages:
- `/collection` — 17 visual entries (some are installation images, not 17 authenticated distinct physical artworks)
- `/language` — The Atomic Language, explicitly framed as a curatorial metaphor
- `/in-context` — installations, interiors and spatial interpretation
- `/patronage` — framework for verified private patrons and institutional partners

## Vercel
Import this folder as a static site. Framework preset: Other. No build command. `vercel.json` enables clean URLs.

## Publication checklist
- Verify and replace working catalogue titles, dimensions, dates, provenance and available inventory.
- Obtain consent/rights for all photographs and artwork reproduction.
- Confirm the enquiry email.
- Obtain written approval and evidence before adding any private fund or bank name/logo or claiming an investment, sponsorship or endorsement.
- Photos of gallery-like spaces are contextual imagery, not independently verified exhibition records.


## V3 Atomic Archive
New `/atomic-archive` page, 17 artwork URLs under `/art/<slug>`, and 17 scannable PNG QR codes in `/qr-codes/`. Upload the whole folder to the SAME Vercel project at https://mark-streben-private-edition-vercel.vercel.app. QR codes encode this domain. QR codes must be regenerated if the domain changes.
